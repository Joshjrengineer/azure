# TradeZilla Lite (Free)

A lightweight, free trading journal web app you can run locally.

## Features

- Add and delete trades.
- Automatic P/L calculation for long and short positions.
- Performance dashboard (net P/L, win rate, average win/loss, profit factor).
- Export your journal to CSV.
- Browser local storage (no account required).

## Quick start

1. Open `index.html` in your browser.
2. Start logging trades.

## Why this helps your trading journey

- Build consistency by journaling every trade.
- Review setups by adding `Setup Tag` and notes.
- Track your edge with objective numbers.
